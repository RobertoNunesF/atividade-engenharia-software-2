# Engenharia de Software II - Prática de Git

Projeto prático para a disciplina de Engenharia de Software II (Prof. Wagner Loch), com foco em controle de versão via Git e implementação de requisitos da classe `Veiculo`.

## Requisitos

- Node.js instalado

## Como rodar

1. Instale as dependências:

   ```bash
   npm i
   ```

2. Execute o projeto:

   ```bash
   npm start
   ```
